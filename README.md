# PACKAGE 1 — DEMO MASTER

This package opens with demo content for Anjan Ghosh.

For each new agent:
1. Edit only `config.js`.
2. Replace `images/agent.jpg` with the agent's photo.
3. Keep `index.html`, `script.js`, and `style.css` unchanged.

Services, Why Choose Me, FAQ, Testimonials and other page content are configured in `config.js`.

WhatsApp QR is generated automatically from `contact.whatsapp` by the dynamic script.


## If you are testing locally
After changing `config.js`, save it and refresh `index.html` with Ctrl+F5.
Make sure you open THIS package's `index.html`, not an older single HTML file.
